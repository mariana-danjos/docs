# Recursos

Vocês têm à disposição boilerplates para a infraestrutura, o shell para o frontend, para o microfrontend e para o microsserviço. Clone os repositórios abaixo no mesmo diretório e use `docker` para rodar a aplicação a partir do repositório `plus-infra`:

- [plus-infra](https://github.com/pucrs-sweii-2026-1-30/plus-infra)
- [plus-shell](https://github.com/pucrs-sweii-2026-1-30/plus-shell)
- [plus-ms-auth](https://github.com/pucrs-sweii-2026-1-30/plus-ms-auth)
- [plus-mfe-auth](https://github.com/pucrs-sweii-2026-1-30/plus-mfe-auth)

Para o ADR, vocês podem utilizar como exemplo o [ADR da aplicação inteira](../about/adr.md), focando neste caso no escopo desta entrega.
